# DSA Practice Platform

Practise data-structures-and-algorithms problems: pick a topic and difficulty, get hints, submit JavaScript, and
see it judged live in a sandbox. One engine, four front ends.

| Part | Folder | Start here |
|---|---|---|
| Backend (API + worker) | `server/`, `workers/`, `core/` | **[server/README.md](server/README.md)**: running in ~5 minutes |
| Web | `web/` | `npm run dev -w web` |
| Desktop | `desktop/` | `npm run dev -w desktop` |
| Mobile | `mobile/` | `npm run start -w mobile` |
| CLI | `cli/` | `npm run start -w cli` |

Docs: [architecture](docs/architecture.md) · [API (OpenAPI)](docs/openapi.yaml), also served at `/docs` ·
[report part 1](docs/report/part-1.md) · [demo script](docs/demo-script.md) · [handovers](docs/handover/).
